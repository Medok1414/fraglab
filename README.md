# FragLab — платформа для киберспортивных тренировок

Учебный проект по УП.09.01. PHP 8 + MySQL (XAMPP), без фреймворков.

## Структура

- `index.php` — главная (дисциплины, новые тренировки)
- `trainings.php` — каталог с фильтрами и поиском
- `training.php` — страница тренировки, запись на неё
- `coaches.php` — тренеры
- `coach.php` — страница тренера: расписание и запись на занятие по времени
- `help.php`, `contacts.php` — помощь и контакты (API Яндекс Карт)
- `register.php`, `login.php`, `logout.php` — регистрация и вход
- `cabinet.php` — личный кабинет (мои тренировки, прогресс, занятия с тренерами)
- `admin/` — админ-панель (добавление, изменение, удаление записей)
- `admin/queries.php` — таблицы представлений (5 SQL VIEW), только для администратора
- `database/fraglab.sql` — структура БД, тестовые данные, представления
